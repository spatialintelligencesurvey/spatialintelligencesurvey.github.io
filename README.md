# Spatial Intelligence Survey

Website for *A Survey of Spatial Intelligence Benchmarks for MLLMs, VLAs, and World Models*.

Published version: **v0.8** (maintenance update, 29 October 2026).

[Read the survey](https://spatialintelligencesurvey.github.io/).

This update contains 9 chapters, 3 benchmark summary tables, and 113 bibliography entries. It expands concrete action and world-construction examples, aligns task definitions with the tables, organizes evaluation metrics by task, and separates output formats, evaluation reliability, and data sources. The Learning and Real-to-Sim sections are temporarily omitted. It retains the original author-provided taxonomy figure (`framework.png`) and the caption “Fig. 1. Overview of the taxonomy.” The page embeds its styles and original figure and requires no runtime service.
